Modern architectures for long context models 1m token windows build on the transformer architecture, which revolutionized deep learning with its self-attention mechanism. ```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "meta-llama/Llama-3-8B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name, torch_dtype=torch.float16, device_map="auto"
)

prompt = "Explain the key concepts of {} in detail:".format("{topic}")
inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
