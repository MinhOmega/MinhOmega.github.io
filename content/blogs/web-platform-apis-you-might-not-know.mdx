## Introduction

The web platform provides dozens of powerful APIs that many developers don't know about. These APIs solve common problems without requiring external libraries—from observing element sizes and visibility to managing navigation and animations. This guide covers the most useful underused Web APIs with practical examples and browser support information.

## IntersectionObserver

`IntersectionObserver` efficiently detects when elements enter or exit the viewport. It's far more performant than scroll event listeners.

```javascript
// Lazy load images as they enter the viewport
const imageObserver = new IntersectionObserver(
  (entries) => {
    entries.forEach((entry) => {
      if (entry.isIntersecting) {
        const img = entry.target;
        img.src = img.dataset.src;
        img.srcset = img.dataset.srcset || '';
        img.classList.add('loaded');
        imageObserver.unobserve(img);
      }
    });
  },
  {
    rootMargin: '200px 0px', // Start loading 200px before visible
    threshold: 0.01,
  }
);

document.querySelectorAll('img[data-src]').forEach((img) => {
  imageObserver.observe(img);
});
```

**Infinite scroll pattern:**

```javascript
const sentinel = document.querySelector('#sentinel');
const list = document.querySelector('#list');

const scrollObserver = new IntersectionObserver(async (entries) => {
  if (entries[0].isIntersecting) {
    const items = await fetchNextPage();
    items.forEach(item => {
      const li = document.createElement('li');
      li.textContent = item.name;
      list.appendChild(li);
    });
  }
});

scrollObserver.observe(sentinel);
```

## ResizeObserver

`ResizeObserver` watches elements for size changes—far better than listening to window resize events.

```javascript
const resizeObserver = new ResizeObserver((entries) => {
  for (const entry of entries) {
    const { width, height } = entry.contentRect;
    const element = entry.target;

    // Responsive behavior based on element size, not viewport
    if (width < 300) {
      element.classList.add('compact');
    } else {
      element.classList.remove('compact');
    }

    // Update chart dimensions
    if (element.dataset.chart) {
      charts[element.dataset.chart].resize(width, height);
    }
  }
});

document.querySelectorAll('[data-responsive]').forEach((el) => {
  resizeObserver.observe(el);
});
```

**Responsive text sizing:**

```javascript
const textObserver = new ResizeObserver((entries) => {
  entries.forEach((entry) => {
    const { width } = entry.contentRect;
    const fontSize = Math.max(14, Math.min(24, width / 20));
    entry.target.style.fontSize = `${fontSize}px`;
  });
});
```

## Web Animations API

The Web Animations API provides a JavaScript interface to CSS animations with more control and composability.

```javascript
// Animate an element
const element = document.querySelector('.box');

const animation = element.animate(
  [
    { transform: 'translateX(0)', opacity: 1 },
    { transform: 'translateX(100px)', opacity: 0.5 },
    { transform: 'translateX(200px)', opacity: 1 },
  ],
  {
    duration: 1000,
    easing: 'ease-in-out',
    fill: 'forwards',
    iterations: 2,
  }
);

// Control playback
animation.pause();
animation.play();
animation.reverse();
animation.cancel();

// Wait for completion
await animation.finished;
console.log('Animation done');
```

**Staggered animations:**

```javascript
function staggerAnimation(elements, delay = 100) {
  elements.forEach((el, index) => {
    el.animate(
      [
        { opacity: 0, transform: 'translateY(20px)' },
        { opacity: 1, transform: 'translateY(0)' },
      ],
      {
        duration: 300,
        delay: index * delay,
        fill: 'forwards',
        easing: 'ease-out',
      }
    );
  });
}
```

## Navigation API

The Navigation API provides programmatic control over browser navigation, replacing the older History API with a cleaner interface.

```javascript
// Listen for navigation events
navigation.addEventListener('navigate', (event) => {
  const url = new URL(event.destination.url);

  // Intercept the navigation
  if (url.pathname.startsWith('/app')) {
    event.intercept({
      async handler() {
        const content = await loadRoute(url.pathname);
        document.querySelector('#app').innerHTML = content;
        updateActiveLink(url.pathname);
      },
    });
  }
});

// Programmatic navigation
navigation.navigate('/dashboard', {
  state: { from: 'home' },
  info: { transition: 'slide' },
});

// Go back
navigation.back();

// Access current state
console.log(navigation.currentEntry.getState());
```

## Scheduler API

The Scheduler API helps break up long tasks to keep the main thread responsive.

```javascript
// Yield to the main thread
async function processItems(items) {
  for (let i = 0; i < items.length; i++) {
    processItem(items[i]);

    // Yield every 50 items to keep UI responsive
    if (i % 50 === 0 && 'scheduler' in globalThis) {
      await scheduler.yield();
    }
  }
}

// Post a task with priority
if ('scheduler' in globalThis) {
  scheduler.postTask(() => {
    // High priority: user-visible work
    updateUI();
  }, { priority: 'user-blocking' });

  scheduler.postTask(() => {
    // Low priority: background work
    prefetchData();
  }, { priority: 'background' });
}
```

## DocumentPictureInPicture API

Open a picture-in-picture window with any HTML content, not just video.

```javascript
async function openPiP() {
  if (!('documentPictureInPicture' in window)) return;

  const pipWindow = await documentPictureInPicture.requestWindow({
    width: 400,
    height: 300,
  });

  // Add content to the PiP window
  pipWindow.document.body.innerHTML = `
    <style>
      body { font-family: system-ui; padding: 16px; margin: 0; }
      .timer { font-size: 48px; font-weight: bold; text-align: center; }
    </style>
    <div class="timer" id="timer">00:00</div>
  `;

  // Update the PiP window from the main page
  const timerEl = pipWindow.document.getElementById('timer');
  let seconds = 0;
  const interval = setInterval(() => {
    seconds++;
    timerEl.textContent = new Date(seconds * 1000).toISOString().substr(14, 5);
  }, 1000);

  pipWindow.addEventListener('pagehide', () => clearInterval(interval));
}
```

## View Transitions API

Smooth transitions between different page states or views.

```javascript
// Transition between views
async function switchView(newContent) {
  if (!document.startViewTransition) {
    updateDOM(newContent);
    return;
  }

  const transition = document.startViewTransition(() => {
    updateDOM(newContent);
  });

  await transition.finished;
  console.log('Transition complete');
}
```

## BroadcastChannel API

Communicate between tabs, windows, or workers on the same origin.

```javascript
// Tab 1: Send a message
const channel = new BroadcastChannel('app-sync');
channel.postMessage({ type: 'logout', userId: '123' });

// Tab 2: Receive the message
const channel = new BroadcastChannel('app-sync');
channel.addEventListener('message', (event) => {
  if (event.data.type === 'logout') {
    handleLogout(event.data.userId);
  }
});
```

## Best Practices

1. **Check browser support**: Use feature detection before using newer APIs
2. **Use observers over event listeners**: IntersectionObserver and ResizeObserver are more performant
3. **Unobserve when done**: Clean up observers to prevent memory leaks
4. **Provide fallbacks**: Use progressive enhancement for newer APIs
5. **Test across browsers**: Some APIs have limited Safari support

## Common Pitfalls

| Pitfall | Impact | Solution |
|---------|--------|----------|
| No cleanup for observers | Memory leaks | Unobserve when elements are removed |
| Using scroll events for visibility | Poor performance | Use IntersectionObserver |
| window.resize for element size | Incorrect measurements | Use ResizeObserver |
| No feature detection | Crashes in older browsers | Check for API support first |

### File System Access API

The File System Access API allows web applications to read and write files on the user's local file system with their explicit permission. This API enables web-based code editors, image editors, and document processors to work with local files seamlessly. The showOpenFilePicker and showSaveFilePicker methods present native file dialogs. The showDirectoryPicker method grants access to an entire directory, enabling bulk file operations. All access requires user interaction and permission, and the API includes security sandboxing to prevent malicious access. Use this API to build rich file-based applications that rival desktop software capabilities.

### Credential Management API

The Credential Management API provides a standardized way to handle user sign-in across different authentication mechanisms. Use the navigator.credentials.get method to retrieve stored credentials, which may include passwords, federated credentials, or passkeys. The navigator.credentials.store method saves credentials after successful sign-in. The API integrates with browser password managers and the WebAuthn standard for passwordless authentication. Implement the Credential Management API to provide a seamless sign-in experience that works across devices and platforms. Combine it with WebAuthn for strong, phishing-resistant authentication using biometrics or security keys.

### Payment Request API

The Payment Request API provides a standardized checkout flow that reduces friction in web-based purchases. The API presents a native payment UI that collects shipping and payment information from the user's stored payment methods. Use the PaymentRequest constructor to define the supported payment methods, line items, and shipping options. The API handles address validation, payment method selection, and transaction authorization. Implement the Payment Request API to improve conversion rates by reducing the number of steps required to complete a purchase. The API integrates with Apple Pay, Google Pay, and browser-stored payment methods for a seamless checkout experience across platforms.

### Screen Wake Lock API

The Screen Wake Lock API prevents the device screen from dimming or locking while your application needs to remain visible. Use navigator.wakeLock.request to acquire a screen wake lock. The lock is automatically released when the user switches tabs or minimizes the browser. Re-acquire the lock when the page becomes visible again using the visibilitychange event. This API is essential for applications that display real-time information like dashboards, navigation, fitness tracking, or presentation tools. The API requires a secure context and user activation, and it gracefully handles cases where the device does not support wake locks.
### Navigation API

The Navigation API provides a modern replacement for the History API with improved ergonomics and features. Use the navigation.navigate method to programmatically navigate to a new URL. The navigation API provides intercept events that allow you to handle navigation requests before they complete, enabling custom loading logic, confirmation dialogs, and route guards. The navigation.currentEntry property provides information about the current URL including its URL object and state data. The navigation API handles same-document navigations differently from cross-document navigations, giving you fine-grained control over how navigations are processed. This API simplifies client-side routing and provides a better foundation for single-page application frameworks.

### Compression Streams API

The Compression Streams API provides built-in support for compressing and decompressing data using gzip, deflate, and deflate-raw formats. Create a CompressionStream or DecompressionStream and pipe data through it using the Streams API. This enables client-side compression for file uploads, reducing bandwidth usage and upload times. Use decompression to process compressed data received from the server without requiring a decompression library. The API runs in both the main thread and workers, so you can perform compression in a background thread to avoid blocking the user interface. This eliminates the need for JavaScript compression libraries and provides native performance.

### Notification API

The Notification API allows web applications to display system-level notifications to users. Request permission using Notification.requestPermission, then create notifications using the new Notification constructor. Notifications appear outside the browser window in the operating system's notification center. Use notifications for alerts, reminders, and updates that require the user's attention even when they are not actively viewing your application. Combine the Notification API with service workers to show notifications from background processes. Handle notification clicks to navigate the user to the relevant content in your application. Use the actions property to add interactive buttons to notifications.

### The Web Locks API

The Web Locks API enables coordination between different browser contexts (tabs, workers, iframes) that share the same origin. This is particularly useful for applications that run in multiple tabs simultaneously. For example, an IndexedDB migration that runs in one tab should prevent other tabs from accessing the database in an inconsistent state. The navigator.locks.request method acquires a named lock and executes a callback while holding it. Other contexts attempting to acquire the same lock will wait until the lock is released. This coordination mechanism prevents race conditions and data corruption in multi-tab web applications.
