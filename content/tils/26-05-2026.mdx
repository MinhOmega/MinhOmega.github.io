- **Theme toggle, click-origin reveal** — ported [`react-theme-switch-animation`](https://github.com/MinhOmega/react-theme-switch-animation) into this site. `Math.hypot` to the four viewport corners → guaranteed-cover radius; `documentElement.animate({ clipPath }, { pseudoElement: '::view-transition-new(root)' })` to drive it; `flushSync` inside `startViewTransition` so React commits before the snapshot; `prefers-reduced-motion` respected.
- **Cloudflare edge stack on Astro 6** for [hoatuoidanangnhanhi.com](https://hoatuoidanangnhanhi.com) — one `_worker.js/` wrapper bundles Pages Functions + Astro SSR + R2-served `/media/*` into a single deploy. Per-page SSR via `export const prerender = false` keeps static catalog pages alongside dynamic checkout.
- **RAG without leaving the edge** — Workers AI + Vectorize, dispatched through Vercel AI SDK to Gemini (primary) + OpenRouter (fallback) via **Cloudflare AI Gateway**. AI Gateway gives per-provider caching, rate limits, and analytics in one config — no more direct provider calls from a Worker.
- **Vietnamese-first patterns** — store `name` *and* a diacritic-stripped `search_name` column in D1 for tolerant search, generate **VietQR** bank-transfer codes server-side for checkout.
- **Cache-poisoning lesson** — CDN cache keys must not vary on session cookies for endpoints that should be public, or a single authed POST poisons the public response.
- **Partytown** moves GA4 / GTM / Pixel into a Web Worker so analytics never block the main thread; image pipeline locked to WebP behind a CI audit step.
- Shipped a small [`crawler-fgo.vn`](https://github.com/MinhOmega/crawler-fgo.vn) Python crawler — splitting fetch from normalization made it trivially portable to a second site later.
