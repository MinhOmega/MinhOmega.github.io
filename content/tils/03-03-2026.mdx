- Released **[Capturia](https://github.com/MinhOmega/Capturia)** — open-source Screen Studio alt on Electron + PixiJS. PixiJS beats raw `<canvas>` for the editor preview (GPU cursor effects + zoom at 60fps). Details on [/projects/capturia](/projects/capturia).
- macOS unsigned-app unblock: `xattr -rd com.apple.quarantine "/Applications/<App>.app"` clears Gatekeeper without code-signing.
- Shipped two takes on the same idea: **[GitAccountSwitcher](https://github.com/MinhOmega/GitAccountSwitcher)** (Swift/SwiftUI) vs **[git-account-switcher](https://github.com/MinhOmega/git-account-switcher)** (Electrobun + Bun). Verdict: Electrobun installers ~10× smaller than Electron, SwiftUI still wins first-paint and idle memory. See [/projects/git-account-switcher](/projects/git-account-switcher).
- Transactional credential switching: snapshot Keychain + `git config` + `gh auth` state before any write, replay the inverse on failure.
- AES-256-GCM is the right call for encrypted JSON on disk — built-in auth tag means tampering surfaces as a decode error, no separate HMAC.
- Built **[interview-coder](https://github.com/MinhOmega/interview-coder)** + **[interview-assistant](https://github.com/MinhOmega/interview-assistant)** — invisible window via transparent frameless `BrowserWindow` + `setContentProtection`. See [/projects/interview-coder](/projects/interview-coder).
- [models.dev](https://models.dev) (3,000+ LLMs with pricing/context) wired as a 3-tier fallback (provider API → models.dev → static) so the settings UI is never empty.
- Karpenter NodePool `limits: 0` during off-hours scale-down (otherwise Redis re-provisions a baseline node); ACR cleanup must abort on unreachable clusters or it cascade-deletes live images.
- **`pg_trgm`** trigram index on managed Postgres replaces a third-party lib for tolerant Vietnamese search.
- Astro on Cloudflare D1: always parameterize queries — never string-interpolate user content. `$` collisions with PG-escape surface as cryptic errors.
- AKS ingress-nginx pre-stop hook (`lifecycle.preStop.exec: sleep 15`) fixes rolling-deploy downtime by letting in-flight requests drain.
- **E2B sandbox templating**: files uploaded to `/home/user/` get baked into the snapshot — runtime mutations don't persist unless you snapshot again.
- Karpenter/NAP doesn't auto-rebalance pods across nodes — only schedules new ones; need `descheduler` or PDB-driven rolling (caveat to the [Feb entry](/til#2026-02-14)).
- **resumable-stream**: a `cancelStream` reusing the existing request channel beats opening a separate cancel topic (doubles Redis traffic).
- Dangling `asverify` CNAMEs are a subdomain-takeover vector — sweep them on cert rotation.
