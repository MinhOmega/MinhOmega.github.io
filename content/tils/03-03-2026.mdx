- Released **[Capturia](https://github.com/MinhOmega/Capturia)** — an open-source Screen Studio alternative built on **Electron + React + Vite + PixiJS + dnd-timeline**. Forked from [OpenScreen](https://github.com/siddharthvaddem/openscreen) and rebuilt the macOS-native capture helper so the cursor hide/show behavior no longer relies on a fragile JS overlay.
- Learned the **macOS unsigned-binary unblock**: `xattr -rd com.apple.quarantine "/Applications/Capturia.app"` clears the Gatekeeper flag without code-signing. Pairing it with a permissions diagnostics screen (Screen Recording + Accessibility + Microphone + Camera) catches 90% of "it won't record" support tickets.
- Discovered **PixiJS** is dramatically better than a raw `<canvas>` for the video editor preview: GPU-accelerated cursor effects + zoom transforms run at 60fps even when stacked with overlays.
- Shipped **[GitAccountSwitcher](https://github.com/MinhOmega/GitAccountSwitcher)** (native **Swift + SwiftUI**) and **[git-account-switcher](https://github.com/MinhOmega/git-account-switcher)** (**Electrobun + Bun + native macOS WebView**) as a head-to-head DX experiment. Verdict: Electrobun installers are ~10× smaller than Electron, SwiftUI still wins first-paint and idle memory for menu-bar apps.
- Learned **transactional credential switching**: composing Keychain writes + `git config` writes + `gh auth switch` into one unit with rollback on any failure. The trick is to snapshot every target before the first write and replay the inverse on error.
- **AES-256-GCM** is the right call for "encrypted JSON on disk" — built-in authentication tag means tampering surfaces as a decode error, no separate HMAC needed.
- Built two AI interview helpers: **[interview-coder](https://github.com/MinhOmega/interview-coder)** (Electron v35, OpenAI/Gemini/Claude/Ollama) and **[interview-assistant](https://github.com/MinhOmega/interview-assistant)** (Electron 29 + Whisper + Gemini Audio for live transcription, **invisible window** via transparent frameless `BrowserWindow` + `setContentProtection` so most screen recorders capture an empty rectangle).
- Discovered **[models.dev](https://models.dev)**: an open-source catalog of **3,000+ LLMs** with pricing and context windows. Wired it as a 3-tier fallback (provider API → models.dev → static defaults) so the settings UI always has *something* to show.
- Learned that **`ProviderClientFactory`** is the right abstraction: one function returns a unified streaming client for OpenAI / Gemini / Anthropic / Azure / OpenRouter, so the UI never branches on provider.
